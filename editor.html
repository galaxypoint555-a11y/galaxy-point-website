How to Use This Panel

Four simple steps — anyone authorised can manage the website.

1
Choose what you want to change

Homepage Video, Banners & Offers, Products & Stock, or Category Photos.

2
Upload or edit

Upload new video/photo, type product name or price, set available stock. No code required.

3
Open Website Preview

Check the draft display before publishing. Only visible products appear in the preview.

4
Press Publish Website Updates

Saves supported homepage text and banner settings to Supabase. Verify changes on the actual website.

Important: This editor uses staff sign-in and cloud operations for supported content. Checkout and website integration must be tested separately.
